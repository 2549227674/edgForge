## 读取约定

- `G`：已被 Git 跟踪（含被 `git add -f` 冻结的小型结果快照）。
- `G*`：目录内至少有一个 Git 跟踪文件；目录仍可能同时含本地生成物。
- `U`：本地未跟踪。
- `I`：被 `.gitignore` 忽略的本地生成物。
- 索引只读取路径、层级、文件数和文件大小，不读取文件内容。
- 虚拟环境、第三方源码、大型数据集和高扇出 trial 目录折叠为汇总行。

## 更新方式

目录布局、模型、数据、结果或 VM 有显著变化后，运行：

```bash
python3 scripts/generate_local_project_index.py > docs/本地项目目录索引.md
```

提交前应审阅输出：它会记录本地文件名和层级，但不会把被索引文件的内容带入 Git。
