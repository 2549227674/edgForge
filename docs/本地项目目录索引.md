## 读取约定

- `G`：已被 Git 跟踪，包含使用 `git add -f` 冻结的小型结果快照。
- `G*`：目录内至少有一个被跟踪文件，也可能同时含本地生成物。
- `U`：本地未跟踪。
- `I`：被 `.gitignore` 忽略的本地生成物。
- 此文件记录路径、层级、Git 状态、文件数与大小等元信息；不读取或提交被索引文件的内容。
- 虚拟环境、第三方源码、归档数据集和高扇出 trial 目录只列目录级摘要，避免索引退化为数万行原始 `tree` 输出。

## 更新方式

目录布局、模型、数据、结果或 VM 有显著变化后，从项目根目录运行：

```bash
python3 scripts/generate_local_project_index.py > docs/本地项目目录索引.md
```

再审阅目录树、用途说明和 Git 状态的变化，并与生成器一起提交。该命令仅把路径和元信息写入索引，不会把模型、日志、密钥、数据集或结果文件的内容加入 Git。
