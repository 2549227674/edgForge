# EdgeForge · 历史调研资料索引

本目录保存 EdgeForge 在 2026-07 形成蓝图前使用的事实台账、分轮调研报告和面经资源库。它们用于追溯“当时为什么这样判断”，不是当前执行说明，也不随项目实测持续回填。

## 1. 权威边界

按问题类型选择入口：

| 要回答的问题 | 当前入口 |
|---|---|
| 机器、模型、评测和板端的实测值 | `eval_config.yaml`、`logs/`、冻结证据包 |
| 当前里程碑状态与操作边界 | 对应执行卡；M0 为 [`docs/m0/README.md`](../m0/README.md) |
| 跨里程碑机制事实与纪律 | [`docs/facts.md`](../facts.md) |
| 项目计划与决策 | [`EdgeForge 蓝图终稿 v4-R2`](../EdgeForge_蓝图终稿_v4-R2_2026-07-19.md) |
| 2026-07 调研过程、来源和旧判断 | 本目录 |

若调研归档与上述当前入口冲突，以实测证据和当前文档为准；不得用历史报告反向覆盖实测。

## 3. 维护规则

- 历史报告正文原则上冻结；只允许补归档说明、修复断链或明显排版错误。
- 新实测进入证据、执行卡或 `docs/facts.md`，不回填进 R1–R4。
- 历史报告中的计划建议不构成执行授权；是否执行以蓝图和当前里程碑卡为准。
- 不为了“消除冲突”合并 R1a/R1b 等独立输出；差异本身属于调研过程证据。
